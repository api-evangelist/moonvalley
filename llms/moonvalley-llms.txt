# Moonvalley

> Moonvalley is an AI research lab building Marey, a studio-grade generative video model for filmmakers. Marey produces cinematic image-to-video and text-to-video with precise controls (pose transfer, camera control, motion transfer, trajectory control), trained on licensed data and marketed as "commercially safe." A first-party public API is announced but currently waitlist-only; Marey is available today through inference partners fal.ai and ComfyUI.

## Products
- [Marey](https://www.moonvalley.com/): Studio-quality AI video generation from images or text, with filmmaker-grade motion, lighting, and camera controls.

## Developers
- [Public API (waitlist)](https://www.moonvalley.com/api): Sign up to be alerted when the public API becomes available. No public API reference, SDK, or OpenAPI is published yet.
